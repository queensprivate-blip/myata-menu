# Интеграция функций ПосиДыма v0.35 в МЯТУ

Базой оставлен текущий проект МЯТЫ. Дизайн, меню, фотографии, логотип, фон, контакты и группировка МЯТЫ сохранены.

Добавлено/обновлено:
- продвинутая админ-панель: поиск без потери фокуса, фильтр, черновик новой позиции, конечная категория, объём/описание/цена, фото, стоп-лист, архив, CRUD категорий/акций/правил/настроек;
- безопасные имена файлов Supabase Storage и компактный preview;
- remote-only позиции из Supabase появляются в публичном меню;
- публичное меню перечитывается после изменений админки;
- подсказка «Информация о заведении» под кликабельным логотипом;
- правило 18+ в карточке заведения;
- опциональный Telegram в настройках заведения;
- центрирование последней плитки при нечётном количестве в двухколоночных сетках;
- актуальный слой адаптивности админки v0.35.

Уже было в МЯТЕ и сохранено:
- Мой выбор;
- двухуровневая структура меню;
- быстрая навигация;
- кальянная карусель;
- карусель акций;
- отзывы;
- Supabase Auth и local fallback/remote override.
