# QR Menu Template

Универсальный шаблон мобильного QR-меню на Vite, обычном JavaScript и Supabase.

## Сохранённый функционал

- мобильная главная страница;
- разделы бара, кальянов, акций и правил;
- карусели;
- «Мой выбор» с локальным сохранением;
- окно информации о заведении;
- ссылка на отзывы;
- полноценная админка;
- категории, позиции, цены, описания и сортировка;
- стоп-лист и архив;
- акции и правила;
- настройки заведения;
- загрузка фотографий в Supabase Storage;
- Supabase Auth и RLS.

## Быстрая настройка бренда

Открой `src/brand-config.js` и измени:

- `venueName`;
- `venueType`;
- адрес, телефон и часы;
- ссылку на отзывы;
- цвета темы.

Замени:

- `src/generic-logo.svg` на свой логотип;
- `src/lounge-background-premium.webp` на фоновое изображение.

Можно оставить имена файлов прежними, тогда код менять не придётся. Человечество редко получает настолько удобную сделку.

## Supabase

1. Создай новый проект Supabase.
2. Выполни `supabase/schema.sql`.
3. Выполни `supabase/upgrade-v22.sql`.
4. При необходимости выполни `supabase/seed-demo.sql`.
5. Создай пользователя в Authentication.
6. В `supabase/make-admin.sql` укажи его email и выполни запрос.
7. Добавь переменные из `.env.example` в Vercel.

## Админка

`https://your-domain/#admin`
